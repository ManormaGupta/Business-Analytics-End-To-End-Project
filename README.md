# 📊 Corporate Sales Performance Analytics (End-to-End Project)

---

## 📌 Project Overview
This project demonstrates a comprehensive, end-to-end data analytics workflow designed to extract, transform, and visualize enterprise business sales data. The core objective is to deliver actionable, data-driven insights to corporate stakeholders regarding product performance, revenue generation, and regional category distributions using an automated data pipeline.

---

## 🛠️ Tech Stack & Tools Used

| Phase | Tool / Technology | Purpose |
| :--- | :--- | :--- |
| **Project Management** | 🟢 Jira Software | Agile Kanban Board methodology & workflow tracking |
| **Data Automation** | 🐍 Python (`mysql.connector`) | Data Extraction, automated insertion & validation |
| **Database Design** | 🐬 MySQL Workbench | Structured Querying, schema management (`businessdb`) |
| **Spreadsheet Insights** | 📊 MS Excel | Pivot Tables, Slicers, and initial interactive dashboards |
| **Business Intelligence** | 💛 Power BI Desktop | ETL via Power Query, Data Modeling, and KPI tracking |

---

## ⚙️ Architecture & Workflow

### 🔹 Phase 1: Database Setup & Python Automation
* **Dynamic Generation:** Developed a robust Python backend script to dynamically generate the database structure and the central `sales_data` table.
* **Pipeline Automation:** Automated the data insertion pipeline and validated database integrity directly inside MySQL using structured analytical queries.

### 🔹 Phase 2: ETL & Power BI Visualizations
* **Data Connectivity:** Successfully established a live connection between the MySQL source data and Power BI Desktop.
* **Advanced Data Cleansing:** Utilized the **Power Query Editor** to perform extensive data cleansing, identifying and purging irrelevant blank/null rows and columns.
* **Executive Dashboarding:** Constructed dynamic KPI Cards (tracking a total revenue of **251K**), Donut Charts for category market share, and Line Charts for sales quantity distributions.

### 🔹 Phase 3: Agile Project Tracking
* **Industry Standards:** Adhered to industry-standard project monitoring by deploying a structured **Jira board**. This ensured all deliverables aligned perfectly with critical timeline objectives.

---

## 📈 Key Insights Captured

> 💡 **Executive Summary of Sales Metrics:**
* 💵 **Total Sales Generated:** **251K** inside the tracking period.
* ⚡ **Dominant Category:** **Electronics** drives the highest overall volume of total revenue.
* 🏆 **Top Performer:** **Laptops** emerged as the highest-selling individual product in terms of net financial value.
