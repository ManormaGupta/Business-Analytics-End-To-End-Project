Corporate Sales Performance Analytics (End-to-End Project)

📌 Project Overview
This project demonstrates an end-to-end data analytics workflow designed to extract, transform, and visualize business sales data. The goal is to provide corporate stakeholders with actionable insights regarding product performance, sales revenue, and regional category distributions using an automated data pipeline.

🛠️ Tech Stack & Tools Used
Data Extraction & Database Automation: Python (mysql.connector)
Database Management: MySQL Workbench (businessdb)
Spreadsheet Analytics: MS Excel (Pivot Tables, Slicers, Dashboards)
Business Intelligence: Power BI Desktop (Power Query, Data Modeling, KPI Cards)
Project Management: Jira Software (Agile Kanban Board methodology)

⚙️ Architecture & Workflow
Phase 1: Database Setup & Python Automation
Developed a Python backend script to dynamically generate the database structure and sales_data table.
Automated data insertion and validated the records inside MySQL using structured SQL queries.
Phase 2: ETL & Power BI Visualizations
Connected the source data to Power BI Desktop.
Utilized Power Query Editor to perform data cleansing by identifying and removing irrelevant blank/null rows and columns.
Constructed dynamic KPI Cards (tracking total revenue of 251K), Donut Charts for category market share, and Line Charts for sales quantity distribution.
Phase 3: Project Tracking
Adhered to industry-standard project monitoring by implementing a Jira board, ensuring all deliverables met timeline objectives successfully.

📊 Key Insights Captured
Total Sales Generated: 251K
Dominant Category: Electronics drives the highest volume of total revenue.
Top Performer: Laptops emerged as the highest-selling individual product in terms of value.
